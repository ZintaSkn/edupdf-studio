Privacy

This website sets no cookies and does not measure traffic. The SknEDU-studio software works offline, with no usage statistics.

This website

  • No cookies, no audience measurement, no advertising trackers.
  • The request and order forms work in your browser: they send nothing to our server. The message is only sent if you send it yourself, by WhatsApp or e-mail.
  • The site is hosted by Cloudflare (Cloudflare Pages), which may process technical connection data (IP address, browser) to deliver pages and protect the service.
  • The Download page asks GitHub (api.github.com) for the number and files of the latest version, and downloads come from GitHub: GitHub then receives the same technical connection data.

Your requests and orders

The information you send us (name, phone, e-mail address, town or delivery address, items requested, proof of payment and, for a licence, the account e-mail address and computer code) is used only to reply to you, process and deliver your order and issue your licence. It is never sold or passed on. You can ask to see or delete it by writing to us.

The SknEDU-studio software

SknEDU-studio works offline. The software collects no personal data, sends no usage statistics and transfers no information to any other networked system, except in the following cases, all visible and started by the user or their administrator:

The account (e-mail address required, name and school optional) and the trial start date are stored on the computer, encrypted (AES-256-GCM). This information is used only for the trial and to check the licence; it is passed on to no one. It is kept after uninstalling so that the trial cannot be restarted on the same computer.

AI assistant API keys are encrypted on the computer and are never sent anywhere other than the chosen provider. Opened documents stay on the computer; their recovery copies (unsaved documents) are encrypted (AES-256-GCM).

Marks given with the “Grade” tool: the mark, the scale and the comment for each page are saved in the PDF properties (as well as being shown on the paper), so that the grade summary still works after reopening. They therefore travel with the file if it is shared; a PDF containing a single paper only contains that paper's mark.

Third-party components: the services above apply their own privacy policy when the user chooses to use them.
