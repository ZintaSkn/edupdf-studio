⚠️ Windows: warning on first launch

To be transparent: the installer is not code-signed yet with a publisher certificate. When you first run the downloaded file, Windows may show “Windows protected your PC”.

  1. Click More info.
  2. Then Run anyway.

The installer was scanned with no detection by Kaspersky and Microsoft Defender, and its source code is public. On some Windows 11 PCs, Smart App Control may block an unsigned installer: message us on WhatsApp if that happens to you.

Install in 4 steps

  1. Download the file for your system.
  2. Run it (Windows: installer; macOS: drag the app to “Applications”; Linux: make the AppImage executable).
  3. On first start, create your account with your e-mail address.
  4. Enjoy a 30-day trial of every feature.

Good to know

  • Automatic updates on Windows: checked at startup and every 4 hours, installed when you close the app.
  • macOS: the app is not yet signed by Apple; the first time, right-click the app › Open.
  • Linux: chmod +x SknEDU-studio-*.AppImage then run the file.
  • Not supported: Windows 7 / 8 and 32-bit systems. Windows 11 ARM PCs work through emulation.
