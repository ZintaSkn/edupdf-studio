⚠️ Windows : avertissement au premier lancement

Soyons transparents : l'installateur n'est pas encore signé par un certificat d'éditeur. Au premier lancement du fichier téléchargé, Windows peut afficher « Windows a protégé votre ordinateur ».

  1. Cliquez sur Informations complémentaires.
  2. Puis sur Exécuter quand même.

Sur certains PC Windows 11, le Contrôle intelligent des applications bloque l'installateur. Prenez alors la version sans installation (.zip) : extrayez-la, par exemple dans Documents, puis lancez SknEDU-studio.exe. Le logiciel propose les raccourcis Bureau et menu Démarrer, et se met à jour tout seul.

L'installateur a été analysé sans aucune détection par Kaspersky et Microsoft Defender, et le code source du logiciel est public.

Installer en 4 étapes

  1. Téléchargez le fichier de votre système.
  2. Lancez-le (Windows : installateur, ou extrayez la version sans installation ; macOS : faites glisser l'application dans « Applications » ; Linux : rendez l'AppImage exécutable).
  3. Au premier démarrage, créez votre compte avec votre adresse e-mail.
  4. Profitez de 30 jours d'essai de toutes les fonctions.

Bon à savoir

  • Mises à jour automatiques sous Windows : vérification au démarrage puis toutes les 4 heures. Elles s'installent à la fermeture, même quand Windows bloque les installateurs : le contenu, signé par l'éditeur, est vérifié avant d'être remplacé.
  • macOS : l'application n'est pas encore signée par Apple ; à la première ouverture, faites un clic droit sur l'application › Ouvrir. Les nouvelles versions s'y signalent par un lien de téléchargement.
  • Linux : chmod +x SknEDU-studio-*.AppImage puis lancez le fichier.
  • Non pris en charge : Windows 7 / 8 et les systèmes 32 bits. Les PC Windows 11 ARM fonctionnent en émulation.
  • Code source (AGPL-3.0) et historique des versions : GitHub.
