Où recevoir les notifications

Sur votre téléphone (facultatif) : installez l'application gratuite ntfy (Android / iPhone), abonnez-vous à un sujet secret puis indiquez-le ici.

Seul ce PC administrateur envoie les notifications (texte court : type d'événement, utilisateur, poste). Laissez vide pour ne rien envoyer hors de ce PC.

Dossier de gestion

Pour gérer d'autres PC, ce dossier doit leur être accessible : partage réseau de l'établissement, ou dossier OneDrive / Google Drive partagé avec les comptes des postes.

Inscrire un poste

  1. Sur le poste, ouvrez SknEDU-studio → onglet Aide → Administration.
  2. Choisissez « Rejoindre la gestion », sélectionnez ce dossier de gestion et saisissez le mot de passe administrateur.
  3. Option « tous les comptes Windows de ce PC » : les règles s'appliquent aussi aux sessions élèves.

Les règles sont signées numériquement : un utilisateur ne peut pas les modifier. Retirer un poste de la gestion demande le mot de passe administrateur.
